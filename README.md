# 📦 Quriarbox - Logistics Landing Page (Bootstrap 5)

This is a clean and professional logistics/courier service landing page built using the **Bootstrap 5** framework. It demonstrates how to use pre-built components and a responsive grid for business websites.

### ✨ Key Features:
- **Bootstrap Grid:** Fully responsive layout designed for mobile, tablet, and desktop.
- **Service Showcase:** Modern card layouts to highlight delivery and tracking services.
- **Navigation & Footer:** Functional Bootstrap navbar and structured informational footer.
- **Modern UI Components:** Integrated buttons, icons, and forms for a professional look.
- **Typography:** Using Bootstrap's utility classes for clean and readable text.

### 🛠️ Technologies Used:
- **HTML5:** For semantic and organized structure.
- **Bootstrap 5:** For rapid and responsive UI development.
- **CSS3:** For custom styling and branding.
